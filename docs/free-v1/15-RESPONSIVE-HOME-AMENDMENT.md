# Free V1 · 全屏首页与响应式视觉修订

修订 `2026-11-03-responsive-home`；用户本轮视觉指令优先于旧第02号中的固定三列、独立顶栏宽度和装饰图标要求。第14号项目/最近信息结构与时间投影、第12号生活/书签、P1权限及所有数据行为完整继承。

## 设计裁决

采用B的受控宽度网格，结合A的四列节奏与C的差异化表现。固定四列会在分屏/缩放中压窄内容；按实际项目数量平分又会使三张卡拉宽。原生CSS Grid auto-fill保留空轨道，项目使用轻边界容器，最近使用开放的日期列表，两者共享列线与间距。保持按行排列与自然卡片高度，不引入瀑布流。

## 统一尺度

- 顶栏、书签、工作区共享最大1192 CSS px，常规左右至少48px；最大宽度下四列各280px，横向间距24px。
- 列最小宽260px；实际容器达到1112/828/544px时分别可容纳4/3/2列，否则自然降列，极窄时不超过容器宽度。窄于761px视口，左右20/52px、列间距20px，右侧为翻页控件留出独立空间。
- 顶栏72px，窄窗64px；搜索入口228px，窄窗为34px图标。顶栏与工作区左右基准相同。
- 书签默认32px单行，标题到书签6px，底部18px、分隔线后24px；顺序、文件夹、favicon与展开规则不变。
- 工作区标题与筛选在一条基线，标题到内容16px；容器较窄时筛选单独占一行。最近与项目间28px，不在没有项目时保留额外上间隔。
- 项目头48px，正文13px、会话行最小34px，触摸42px；去掉重复会话图标和进入箭头，把宽度留给原始标题。完整标题仍由title、可访问名称及会话详情提供。
- 日期窗口保留日历、日期标题、从属线、5/+12。项目和日期网格统一，不加入新区域或技术标签。
- 历史导航继续位于内容外侧；查询容器设在工作区内容，导航为其同级。无模拟原生页脚或额外底部占位。

## 保护边界

生产修改仅限CSS和conversationRow中装饰SVG；没有修改投影、关系、时间、账号、采集权限、存储、活动、分页、搜索、书签数据或浏览器跳转。newtab.html、bookmark-shelf.ts、view-state.ts经核对无需改动。

## 验证与证据

`tests/browser/layout-responsive.mjs`在隔离Profile安装生产构建，明确合成夹具，旧基线固定为1c2aee3。输出同视口同数据新旧截图、实际CSS视口/DPR/容器/列宽/标题可读宽度、缩放与操作回执。不得把content viewport、设备像素、CSS zoom和浏览器真实缩放混称；原生浏览器界面另行验证。`layout-native-ui.mjs`另行安装未改manifest的完整生产扩展，以X11实际窗口截图、原生快捷键和CSS视口/zoom联合验证Chrome普通标签栏、Edge垂直标签和125%/150%。书签布局专项只在测试manifest中预授予原有可选bookmarks，运行时字节保持构建一致；原生窗口专项使用原封不动的manifest。最终结果与未验证项以原Draft PR #1及同SHA Actions制品为准。
