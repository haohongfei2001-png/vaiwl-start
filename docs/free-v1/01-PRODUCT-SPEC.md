# Free V1 冻结产品规格

## 1. 用户承诺

打开新标签页，看见可继续工作的真实 ChatGPT 项目、会话和自己固定的网站。会话入口保存在本机，不随真实标签关闭而消失。点击入口后进入真实 ChatGPT；正常浏览器地址栏继续负责网页搜索。

首页不是聊天客户端。没有 iframe、AI 整理、原生标签搬移或全网页记录。V1 不读取用户输入正文、AI 回复、附件内容、草稿、完整消息 JSON，也不监听键盘输入内容。

### 术语

| 名称 | V1 的唯一含义 |
|---|---|
| 原生 Project | ChatGPT 实际项目，使用稳定原生 ID，名称不是身份 |
| 会话 / 虚拟标签 | 一个真实 conversation ID 的持久入口；原 VAIWL 所说的“窗口”即这个对象 |
| 项目卡 | 一个 Project 及其会话行；不增加任意“子窗口组” |
| 日期窗口 | Start 为确认 NONE 的会话生成的展示容器，名称为今天、昨天或具体日期；不是 Project，也不是浏览器窗口 |
| 30 天段 | 首页投影范围，包含连续 30 个本地日历日 |
| 待确认 | 账号或 Project 归属没有充分证据的独立入口；UNKNOWN 不等于 NONE |
| 本地资料库 | 此扩展在当前浏览器 profile 中保存的目录，不代表云端所有历史 |

## 2. 冻结范围

必需：新标签页覆盖；历史导入与持续收录；可信 Project/NONE/UNKNOWN；每日主动打开去重；30 天上下分段；原名搜索；关闭标签后重进；网站入口新增、固定、排序、折叠；初次安装与权限失败状态；Chrome/Edge 日用兼容。

不包含：Pro、模型/API key、虚拟主题、自动改名、全文搜索、原生 Project 创建/移动/删除、原生书签同步、跨设备同步、账号密码管理、全站 favicon 抓取、独立浏览器、ChatGPT 宿主工作区挂载。设置只保留与上述功能直接相关的项目。

## 3. 信息结构

首页依次为轻量顶部工具区、网站快捷区、原生项目、无项目日期窗口及独立待确认入口。布局随视口收窄，不增加与 Edge 垂直标签竞争的左侧栏。

**项目卡**：原生项目名和图标 → 最近会话 → “显示更多” → 左侧旧会话展开箭头。整卡不折叠。每项目在选中的 30 天段中至多一张卡；成员中最晚活动决定项目所在段。较旧会话始终随父项目保留，在卡内展开。空 Project、无日期项目在“全部已知”搜索可达，不伪造当天活动。

**无项目区域**：仅接纳明确 NONE。按最新主动打开的本地日期生成今天、昨天、`M月D日`，跨年显示年份；同日按最后打开时刻降序。每条会话只在其最新日期出现一次。只有导入访问时间、没有已确认主动打开的记录，不进入今天/昨天日期窗口，留在“尚未主动打开”子列表或待确认目录。没有数据的日期不生成空日期卡；这不同于必须逐段可达的空 30 天段。

**待确认区域**：区分“归属待确认”（已有账号）与“账号待确认”（浏览记录候选）；不要求用户逐条审批。均可通过标题打开、搜索、移除本地入口。有明确活动时可以按活动排序；没有活动时保持稳定发现顺序。浏览历史时间只作为详情里的浏览器记录，不标为活跃日期。

## 4. 活跃与空间稳定性

### 4.1 活动定义

一次主动打开必须满足：有可接受的用户意图证据 + 精确会话目标 + 成功抵达该目标 + 没有账号或文档冲突。Start 的普通点击、键盘激活、中键/Ctrl/Cmd 点击，及受支持 ChatGPT 原生会话链接的真实点击都可提供意图。明确在后台打开是用户操作，可以记；后台自动加载不能记。

地址栏的全新导航仅在经过实际双浏览器验证的严格规则下计入。刷新、自动恢复、轮询、列表渲染、浏览器 tab 激活或窗口聚焦本身均不计。原生书签、外站链接和切回现有 tab 若缺少可靠主动证据，只收录目录，不能猜测；产品说明写“记录可确认的主动打开”。不能靠增加全站监听消除此限制。

每天去重键为 `(recordKey, libraryTimeZone, localDate)`。同日再打开仍更新 `lastOpenedAt` 与排序候选，但不增加日记录。没有发送次数、停留时长、半个活跃、AI 活跃分数。只打开空白新聊天不产生真实会话记录；初次生成真实会话 ID 时可收录目录，但不因脚本路由自动记活跃。之后明确打开该真实会话才计入。新建/发送意图追踪不进入 V1。

### 4.2 30 天继承

V1 固定 H=30。T 为视图创建时在资料库时区 Z 的本地日期，k≥0：

`W(k) = [T + 1 − 30(k+1), T + 1 − 30k)`

`segment = floor((T − localDay(lastActiveAt, Z))/30)`。

2026-11-02 的当前段为 2026-10-04—2026-11-02；上一段 2026-09-04—2026-10-03。闰年、月末和夏令时不改变 30 个日历日。未来日期/无效时钟不硬塞当前段。上下按钮切换投影；不删除目录、不改原始活动。k=0 不渲染向上按钮；空段不跳过；更早已知记录仍可达。时区初次采用系统 IANA 值并持久保存，旅行不自动重算旧活动日；设置明确变更时区后重新投影时间，既有日记录保留原时区去重键。

继承原 `free-time-policy.mjs` 的日历与分段函数。自动密度 H 和 7/14/60/90 设置不进入 Start V1；原仓的“项目少”自适应也不移植。

### 4.3 排序稳定

项目按成员最新主动活动降序；会话按自身最新主动活动降序；等时保持首次已确认的稳定 rank，再以稳定 ID 兜底。无日期放在对应的未定日期入口。每日次数不参与排名。

打开旧 NONE 会话后，它在下次安全刷新进入今天，原日期不保留重复条目。打开旧项目会话后，整个项目进入当前段，旧成员仍保留。页面正处于 pointerdown、拖动、IME 或键盘选择时暂停视觉重排；操作结束后≤1秒应用，并按 recordKey 恢复焦点与滚动锚。最长不以“稳定”之名无限搁置更新；失焦或隐藏页面回到前台的安全时点应用。浏览中的历史页不会被后台更新强制跳回当前段。

## 5. 打开与历史可达性

普通点击在当前 Start 标签中进入真实 ChatGPT。Ctrl/Cmd+点击和中键新建后台标签，Shift+点击按浏览器习惯打开窗口。不自动复用或重排其他标签，不批量开页，不因 URL 看似相同就跨账号聚焦某个已打开标签。

打开经过“持久意图 → 浏览器导航 → 匹配抵达”流程；没有匹配抵达不提交活动。浏览器自身右键菜单打开可能无法关联意图时，允许打开但保守不记活动。不为计数破坏浏览器链接语义。

会话改名只更新已验证标题，ID 与活动不变。同标题的会话或项目绝不合并。普通 `/c/ID` 与受支持 `/g/container/c/ID` 仅在同一已证账号下合并为相同会话；container hint 不证明 Project。失去访问权限保留入口与清晰状态，不自动删库。

“从首页移除”只删除本地目录并写入防重导入墓碑；不会删除 ChatGPT 会话。需要再次收录时用户明确恢复。关闭真实 tab、清除浏览器历史或退出 ChatGPT不自动删除扩展的已收录目录；设置说明这是一份独立本地副本，并提供清除本地数据。撤销 history 权限停止后续导入，不自动破坏已确认会话。

## 6. 网站快捷入口

由用户输入名称和 http/https URL；不读取整个浏览器书签。图标采用本地字母/内置图形，不请求第三方 favicon 服务。所有项保持同一份用户顺序；固定只决定折叠后的可见性，不自动重排。默认展开普通项，折叠后仅固定项与“更多网站”保留。菜单提供固定/取消、向前/向后、编辑、移除；拖动可用，但键盘菜单必须完成所有操作。

最多两行是默认视觉收纳策略，不是数据上限；展开更多保留所有入口。跨设备同步、自动分类和浏览器真实 Pin Tab 不在 V1。快捷入口点击不改变 ChatGPT 活跃度。

## 7. 首次安装与搜索

第一屏立即可用，提供“打开 ChatGPT”“导入浏览记录”和“添加网站”；不自动弹授权。点连接只申请 ChatGPT 观察所需权限；点导入单独申请 history，并告知该权限在浏览器层面覆盖所有历史，但扩展只保留匹配 ChatGPT 会话的字段。

拒绝授权仍可用网站与已有目录。导入显示进度、可取消、可继续，以及“浏览器当前可读取的记录”范围；不得称完整账号历史。已导入项放入独立待确认入口，开过一次且有真实证据后逐条收敛。

搜索仅检索当前选中资料库的标题、Project 名和保存 URL，不检索正文。可显式切换至未分配记录；不把其他账号结果静默混入。搜索结果标明 Project / 无项目 / 待确认路径，跨 30 天段可达，Esc 还原原位置；空结果有清空条件与打开 ChatGPT 原生搜索的入口。默认不抢焦点，浏览器地址栏仍是新标签页键盘输入起点。

## 8. 账号与离线

已证账号以稳定 principal + workspace/context 区分，账号昵称不充当主键。浏览器 profile 自然隔离扩展存储；同一个 profile 内切换 ChatGPT 账号仍须严格隔离。

历史记录先进入无账号的 staging；当前打开 ChatGPT 的账号不能接管整批导入。用户为资料库起名称只改变标签，不制造身份。离线可以查看明确选中的本地缓存；上次资料库与当前网页登录身份不是同一个状态。新的采集、归属更新与活动确认必须有当前证据；切换时取消旧文档待消费意图。不能承诺自动识别全部账号切换，除非首个真实来源门已经证明此能力。

## 9. 完成标准

首页与数据核心都符合验收表，且真实 Chrome/Edge 能收敛典型 Project 与普通 NONE 会话，才是完整 Free V1。长期所有记录 UNKNOWN 的版本可以是受限目录，但不能标记产品验收完成。原 VAIWL 的 Project 宿主挂载失败不阻塞 Start 自有新标签页的绘制，却不能替代 Start 元数据链的实测。
