# 首页四主题：R1–R6 实现说明

本实现服从第 16 号规范，统一应用于经典、空间 A、分区 B 和书页 C。主题仅决定呈现方式；项目归属、会话身份、活动事实、资料库边界与浏览器跳转沿用既有合同。

## 呈现规则

- 首页和相关设置不再输出项目、会话或窗口计数，包含可访问名称、提示和导入反馈。
- 首页只显示相邻时段箭头。7／30／90 个本地自然日可在「设置 → 新标签页 → 首页布局」选择，默认 30 天。历史浏览按原时段结束日重新定位；空时段仍可逐段翻阅。
- 顶部只有一个工作／生活模式按钮，显示当前模式，通过可访问名称、提示和切换图标说明目标。恢复、保存失败与生活模式资料隔离继续有效。
- 项目预览展示真实成员，标题链接打开原项目；更多成员通过独立的整行展开区域访问。项目卡右上角只有「＋」。
- 最近区由已有投影结果组织为非空的置顶、今天、昨天。三者均无内容时显示所选时段的最近真实日期；独立的末尾箭头展开其余分组。不能确认日期的区间证据使用中性标签。不会将项目成员重新归类为最近。
- 布局默认为按内容自适应。自适应采用最短列补位，DOM 顺序不变，视觉按纵坐标、横坐标顺序与键盘一致；整行展开区域作为分界。等高模式保持同断点一致外部尺寸。尺寸、字体和跨页偏好更新经过 SafeRendering，交互期间不移动目标。

## 原生项目新对话的真实能力边界

当前 `src/domain/ids.ts` 和 `src/collectors/chatgpt/native-projects.ts` 只验证项目落地页 `/g/<project-id>/project`。工程内没有经过验证的项目内新建对话入口，项目落地页不能冒充创建入口。

因此本版本的项目「＋」使用可聚焦的 `aria-disabled` 状态，带有明确的不可用说明，没有导航或伪造创建行为。项目名称和已有会话保持原地址。取得可信原生入口后，才可以在单独的能力变更中启用该按钮；不可退化到通用 ChatGPT 新对话。

## 偏好与视图状态

| 本地偏好 | 值 | 默认值 |
| --- | --- | --- |
| `native.homeTheme` | `classic / spatial / workbench / folio` | `classic` |
| `native.homePeriodDays` | `7 / 30 / 90` | `30` |
| `native.projectLayout` | `adaptive / equal` | `adaptive` |
| `native.recentPinnedKeys` | 用户明确选择的会话键 | 空集合 |

这些偏好分别保存，失败时保留原有效值，支持跨标签页同步，不写入会话事实。生活模式调整布局和主题不会主动读取工作资料库。置顶仅重组当前资料库、当前时段已经有资格进入最近区的记录；其他时段已有的置顶可在管理中取消。

会话完整标题保留在链接文本和悬停提示中。项目展开、日期展开、分页和最近更多分组的视图状态与滚动位置单独保留；主题切换不重置布局选择。

## R1–R6 验证矩阵

| 规则 | 本地代码与单元验证 | 已安装浏览器门禁 |
| --- | --- | --- |
| R1 取消计数 | PASS：共用渲染器无计数，导入／移除文案同步更新 | `home-guardrails.mjs` 全主题检查 |
| R2 设置时间长度 | PASS：自然日、DST、区间边界、历史重定位测试 | 三种长度的真实日期集合与相邻翻阅 |
| R3 单按钮切换 | PASS：单一控件复用原模式控制器 | 四主题语义、生活模式隔离与原生命周期回归 |
| R4 项目唯一加号 | PASS：唯一、可聚焦、明确禁用，无错误导航 | 唯一操作检查；真实原生创建为 NOT_TESTED／未具备能力 |
| R5 最近与置顶 | PASS：非空分组、去重、真实日期回退、中性证据和偏好失败测试 | 置顶／取消／重载、更多分组与历史日期 |
| R6 双布局 | PASS：补位、等高、排序、整行展开、焦点、滚动和清理测试 | 四主题多宽度、实际 200% 浏览器缩放 |

`home-theme.yml` 在精确候选提交上分别运行 Chromium 与 Edge，并保留主题、设置、响应式布局、工作区和书签回归。此文档描述验证范围；具体已安装浏览器结果以对应提交的 CI 收据为准，不能以合成预览代替。生产构建不包含预览夹具。

本分支没有合并到 main，没有发布，也没有替换用户已安装的扩展。
