# Free V1 冻结决策记录

> **当前有效修订：2026-11-02-local-first，用户已批准。** [统一修订合同](10-LOCAL-FIRST-AMENDMENT.md)覆盖原 M0 全局前置门：本地时间组织、Start 主动打开与局部候选项目可独立运行；账号隔离及正式原生归属证明仍保留。`LOCAL_WORKSPACE_READY` 不等于 `FREE_V1_ACCEPTED`。

这些是本轮专业裁决，无需再发起开放式产品讨论。

| ID | 决策 | 理由与边界 |
|---|---|---|
| D01 | 原“窗口”对应真实会话，Project 下不新增自定义分组 | 保留原生组织，避免凭空增加层级 |
| D02 | NONE日期窗与UNKNOWN浏览/活动日期窗均为展示容器 | 显式区分来源与归属；与原生Project分开，无AI聚合 |
| D03 | 项目卡不折叠；网站区可折叠 | 遵守正式 v2.7，同时满足新网站需求 |
| D04 | 固定30日历日，空段不跳过 | 源码继承；不加入自动范围策略 |
| D05 | Start真实手势＋精确浏览器导航完成即主动打开；同日一条 | 不要求正文加载/阅读/发送；账号owner安全不放宽 |
| D06 | 导入浏览时间不回填活动 | history 无法排除恢复/刷新/同步 |
| D07 | UNKNOWN 独立；缺 badge、null、/c/均不能推 NONE | 防止静默错分 |
| D08 | 不继承完整会话详情 GET | 即使最终只保存标题，读取整个响应也会接触正文，违反 V1 |
| D09 | 原“账号与NONE竖切先行”已由用户撤销 | 本地日期窗与活动独立运行，正式来源按字段逐步验证 |
| D10 | 本地工作空间独立验收，正式原生归属另列 | LOCAL_WORKSPACE_READY不等于FREE_V1_ACCEPTED，未证来源不阻断可靠本地能力 |
| D11 | 默认当前标签打开，修饰键保持原生习惯 | 不变成真实标签管理器，不跨账号误复用 |
| D12 | 不设与垂直标签重复的左侧栏 | 给项目区保留宽度 |
| D13 | 默认不自动聚焦站内搜索 | 不劫持浏览器地址栏 |
| D14 | 网站入口不等同浏览器书签或Pin Tab | 更少权限、行为可预测 |
| D15 | 版本化数据交换仅留合同；不实现备份/恢复/云同步 | 本轮不增加数据迁移产品功能或后端 |
| D16 | 只有源码与架构的共享边界，没有双向实时互通 | 不提前实现跨扩展消息、Pro或同步 |
| D17 | 未来Pro仅独立overlay，原生事实不可被AI覆盖 | 为后续留接口，不增加本轮功能 |
| D18 | 标准API与源码可行性不等于真实产品验收 | 发布声明必须分层 |
| D19 | 用户批准2026-11-02-local-first修订 | 撤销全部M0证明先行的共同门，不撤销账号隔离 |
| D20 | UNKNOWN浏览日期和本地主动打开分开显示 | browserLastVisitAt不进入OpenDay/activity |
| D21 | 候选Project只挂原未分配记录 | 按Profile/session/binding/observation隔离，不跨观察合并，不假装正式归属 |
| D22 | 导航完成表示主动打开入口 | 同URL应用错误不等于读取成功，保留旧availability |
| D23 | 旧库原位兼容扩展 | 可选字段，无DB版本变化、清库或批量重导入 |
| D24 | 现阶段只开放已可证实的本地能力 | 正式scope仍需当前owner，真实来源与完整V1验收另列 |
