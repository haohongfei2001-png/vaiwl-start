# Free V1 冻结决策记录

这些是本轮专业裁决，无需再发起开放式产品讨论。

| ID | 决策 | 理由与边界 |
|---|---|---|
| D01 | 原“窗口”对应真实会话，Project 下不新增自定义分组 | 保留原生组织，避免凭空增加层级 |
| D02 | NONE 的日期窗口为展示容器 | 与原生 Project 分开，无 AI 聚合 |
| D03 | 项目卡不折叠；网站区可折叠 | 遵守正式 v2.7，同时满足新网站需求 |
| D04 | 固定30日历日，空段不跳过 | 源码继承；不加入自动范围策略 |
| D05 | 活动=证据充分的主动打开；同日一条、最后时刻可更新 | 用户已明确首版简化，不冒充消息发送 |
| D06 | 导入浏览时间不回填活动 | history 无法排除恢复/刷新/同步 |
| D07 | UNKNOWN 独立；缺 badge、null、/c/均不能推 NONE | 防止静默错分 |
| D08 | 不继承完整会话详情 GET | 即使最终只保存标题，读取整个响应也会接触正文，违反 V1 |
| D09 | 当前源的账号与 NONE 竖切先行 | 原生产默认关闭身份链、NONE未通过；先解决真实依赖 |
| D10 | 元数据适配失败有受限目录降级，完整V1仍不通过 | 有用降级与完成定义分开 |
| D11 | 默认当前标签打开，修饰键保持原生习惯 | 不变成真实标签管理器，不跨账号误复用 |
| D12 | 不设与垂直标签重复的左侧栏 | 给项目区保留宽度 |
| D13 | 默认不自动聚焦站内搜索 | 不劫持浏览器地址栏 |
| D14 | 网站入口不等同浏览器书签或Pin Tab | 更少权限、行为可预测 |
| D15 | 版本化数据交换仅留合同；不实现备份/恢复/云同步 | 本轮不增加数据迁移产品功能或后端 |
| D16 | 只有源码与架构的共享边界，没有双向实时互通 | 不提前实现跨扩展消息、Pro或同步 |
| D17 | 未来Pro仅独立overlay，原生事实不可被AI覆盖 | 为后续留接口，不增加本轮功能 |
| D18 | 标准API与源码可行性不等于真实产品验收 | 发布声明必须分层 |
