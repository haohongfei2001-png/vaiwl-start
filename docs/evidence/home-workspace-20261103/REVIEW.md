# 首页与时间投影独立审查

基线：`17695aeba0b8205c6cbcad7463e89419135d2d7d`。本审查由未实现生产源码的独立测试／审查代理完成；该代理负责新增浏览器专项，不代表另一位 GitHub 人类维护者已批准。

## 源码审查结论

本次检查了时间事实、相对顺序解析、存储接线、纯投影、统一项目渲染、搜索、交互重绘和升级边界。下列确定问题已反馈并在当前源码中修复：

1. **相对时间项目排序丢失依据。** 合并正式／本地项目卡时如果重新使用首成员的精确日期排序，会忽略领域层计算的区间排序值。统一卡片现使用领域 `sortTime`，并以稳定顺序和身份 key 打破相同值。
2. **原生活动顺序压过更近的主动打开。** 原生列表 B→A 不能强制覆盖 A 后来从 Start 打开或浏览的新事实。最终展示排序只保留与独立展示时间相容的相对边；领域回归分别覆盖 Start 和浏览历史。
3. **新认证主体复制旧时间证据。** 新 scoped record 从 staging 创建时不能携带另一身份边界的 `displayTimeFacts` 和 `displayTimeBoundaryKey`。新记录现删除这两个字段；原 staging 记录及其原始证据保留，并有实际 Repository 事务断言。
4. **显式刷新绕过交互保护。** 异步 mutation 返回期间可能开始新的指针、拖动或输入法操作。`refresh(true)` 现也经过 `SafeRendering.render`；仅在没有活动交互时允许立即执行，否则等待交互结束。生产同路径回归覆盖三种门。

## 保留的安全与数据边界

- `src/background/service-worker.ts`、`src/background/navigation.ts`、`src/background/open-broker.ts`、`src/storage/db.ts` 和生产 manifest 与本轮基线没有差异。P1 自动历史前后权限检查、worker/持久代际、事务内停止检查和事务中止机制未被重写。
- `Repository` 的自动授权函数仍保留原检查；新增事实仅在同一合并路径中保留，不创建用户活动。新时间顺序存放在既有 settings store，数据库仍为 version 1、12 stores。
- 缺少成员日期只影响位置，不能删除成员；项目的无日期成员进入项目内“更早”，全无日期／空项目在全局“更早”保留可达性。
- 撤销顺序依据与撤销项目关系分开。后来观察到置顶、部分列表或缺少明确排序语义时，仅移除相应顺序快照；保留成员、已有直接时间事实及原始目录记录。
- 先发现、刷新、Project 页面观察和第一次采集不会创建活动日期。浏览时间、Start 打开和原生更新时间保留各自来源。
- 标题不参与项目身份合并；Profile、scoped owner 和本地主体边界继续隔离。冲突记录可搜索，不被随意归入项目。
- UI 未新增页脚控制权限，没有修改真实 Profile、实验 flags 或使用内部浏览器 API。

## 浏览器专项与证据边界

`tests/browser/home-workspace.mjs` 安装真实生产 JavaScript 到一次性 Profile，并记录源码哈希、浏览器版本、检查项、截图及目录对照。它覆盖以下有意义的端到端路径：

- 活跃／历史项目的完整成员，5→17→18 展开、无日期“更早”、全无日期项目、空项目、历史区间和空区间。
- “最近”、全历史搜索、搜索打开后通过真实导航生成一次 Start 打开，以及无重复记录／OpenDay。
- 同名跨主体、其他 Profile／scope 隔离、冲突记录搜索、十二个 store 的只读展示前后对照。
- 同一真实安装的隔离数据库快照，分别通过固定旧版和候选投影，逐区间比较每个项目的完整成员 key 集合；不是拿两份不同种子数据比较。
- 生产 collector → Repository → 投影 → UI 的相对时间流程；加入置顶干扰、解除干扰、部分加载、补入准确时间后，检查位置纠正与成员不丢失。
- 指针／IME／拖动门的延期重绘；新专项使用明确标注的合成 DOM 门事件，现有 production-ui 专项继续保留真实指针和 CDP 输入法验证。

所有会话、Project、账号边界、浏览历史和 HTTPS 响应均为隔离合成夹具；没有读取用户私人数据。本机当前没有可用浏览器二进制，因此此文件的源码审查结论**不等于**浏览器专项已通过；最终执行结论由同 SHA CI 的实际 JSON 回执决定，不把未运行项写为 PASS。

截图只显示扩展内容视口，不包括 Chrome 控制的原生页脚或 Edge 标签栏图标。Chrome 页脚官方操作与限制见 [PLATFORM.md](PLATFORM.md)。真实 Mac 日常安装、生产 ChatGPT 当前 DOM 是否提供明确时间语义、Edge 原生 NTP favicon 等未由本次合成实装认证。
