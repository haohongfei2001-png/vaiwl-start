# 原生体验修订：分阶段代码与视觉复核

对象：6dfed27之后的本任务差异。由本轮同一工程执行者另行复核，不冒称第二位独立审查者、第三方审计或用户实机验收。最终结果以PR所列commit及同SHA回执为准。

核对领域边界：展示时间为纯函数，拒绝非法/未来时间，保留真实活动字段；正式Project只在scope中关联，UNKNOWN不改NONE；候选仍用观察key、拒绝冲突/撤销，不跨账号靠标题合并。存储仓库与schema源码未修改；唯一相关后台变更是用户显式清除本地数据时删除新增偏好键。

核对权限/写入：bookmarks为optional，原安装仍仅storage。grant在原trusted点击调用，不先await；拒绝不阻断目录。Start书签只读，原生create仅在显式迁移确认后执行；URL规范化、安全校验、全树去重、同源跨标签锁和逐项失败计数。旧shortcuts不因迁移或撤权删除。全树读取不会写本地目录，权限撤销清空内存树。

核对不可信图片/标题：标题以document.title与表单value处理；禁控制/双向字符。图片限MIME、文件字节和尺寸，先头部验证再解码，canvas转PNG移除原数据，拒绝SVG/GIF/脚本。复核修正JPEG EXIF旋转导致宽高互换的合法情况，并维持原始尺寸上限。图标选择有异步序号防止旧上传覆盖新选择；名称/图标分键保存避免相互覆盖。favicon类型根据PNG/SVG更新。

视觉检查：查看隔离浏览器的native-workspace.png、native-settings.png、ui-review.png。白底紧凑，项目容器直接展开真实结构夹具，书签在上方弱化，不再显示来源分栏；设置容器可滚动，标签名称/图标和三种书签习惯可见，无所检查尺寸下的遮挡或溢出。截图为合成数据，不是用户目录。
