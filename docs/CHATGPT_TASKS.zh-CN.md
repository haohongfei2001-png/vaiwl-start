# ChatGPT 定时任务成果 · 安装与使用

此功能让 Start 的工作首页展示已有 ChatGPT 定时任务的真实 AI 输出。它单独开启、单独缓存，不修改任务计划、启用状态或原会话。继承 PR #7 的数据模型与全部 41 项原测试，模型源文件保持不变；首页沿用 PR #6 的四套共享主题。

## 开启

1. 已安装 Start 的用户保留原加载目录和扩展 ID，仅更新运行文件并重新加载。首次安装则解压开发包，在 Chrome/Edge 扩展页加载含 `manifest.json` 的 `vaiwl-start` 文件夹。
2. 在同一个浏览器 Profile 中正常登录 ChatGPT。
3. 打开 Start → 设置 → 工作空间 → ChatGPT 定时任务，开启“同步任务与结果”，允许明确列出的 ChatGPT 网站访问、脚本与定时唤醒权限。会话目录收录和任务同步是两个独立开关。
4. 默认后台页面同步。初次读取后选择首页任务；默认选择最近运行且能读取结果的任务，最多可自行选择十项。
5. 点击首页的成果摘录阅读全文或打开原始来源。可明确标记重要成果、无新信息或执行遇到问题。新失败或无新信息不会覆盖保留的重要成果，详情中仍可查看最近一次输出。

后台同步每 30 分钟尝试一次，在非激活页面中让 ChatGPT 执行自己的正常请求，然后关闭页面，不要求常驻任务页。浏览器关闭、睡眠、退出登录、来源验证或限流期间不能保证更新。页面正常加载有时间上限，不自动解验证、不重试限流、不修改浏览器凭证。如果用户主动切到临时页面，扩展交还该页面，不再自动关闭。

也可选择“仅访问 ChatGPT 时同步”。开启后重新访问任务页，再打开所需任务的执行结果即可收录。关闭任务同步会失效正在进行的写入并保留已有成果；“隐藏首页组件”和“关闭结果预览”不等于停止同步。生活首页会清除任务标题、摘录与详情的页面内容。打开明确的工作空间设置时才可在生活模式管理任务。

## 显示与来源边界

- “已收录输出”只证明最终 AI 正文已读取，不代表任务业务成功。普通浏览器来源没有提供调度运行状态时，明确显示未知；运行完成、业务成功、无新信息和同步失败互不替代。
- 不推算下次运行时间。来源未提供时显示缺失，已保留成果继续显示原来的产生时间与读取时间。
- 原始回复仅按纯文本展示。摘录不是另一次 AI 摘要；链接只采用正文中明确存在的网址及已验证的原会话入口。
- 目前支持带标准 ChatGPT `conversation_id` 的任务输出。仅含 Dot/Work `aeon_id` 的任务可读取元数据，但不冒充已接入正文。
- 列表覆盖只在三个原生分类的首个请求都返回空游标时标为完整。后续页或未读取游标保持部分范围，不把缺席条目当作删除，不猜测分页接口。
- 范围是当前 Profile、当前登录主体及来源直接返回的 team 字段。不同 Profile/账户不合并；未能确认身份或切换账户后不展示旧账户内容。它不等于全账号所有 Workspace 的认证或全量历史同步。
- 正文保存在独立 `vaiwl-start-chatgpt-tasks` IndexedDB。既有 `vaiwl-start` 的版本和 12 个 store 不变。清任务缓存不清原目录；明确“清除全部 Start 本地数据”会清两个本地资料库的记录。均不删除 ChatGPT 内容。

## 可复核的交付边界

实际浏览器与本地/CI 的证据分开记录。带真实正文的截图和原始响应只留在执行者的私有本地工作目录，公开仓库及 CI 不包含真实任务标题、ID、正文、会话或凭证。

- A（Service Worker 直接读取）：真实浏览器认证状态下仍返回 401，未采用。没有提取 bearer token、cookie 或导出凭证。
- B（临时后台页面）：已在真实 Chrome 156 中验证，从没有 ChatGPT 标签页开始，自动取得真实任务列表和完整 331 字输出，首页与全文逐字核对成功，结束后没有遗留来源页、未激活测试页。使用原生页面自己的请求，动态观察器仅把任务标记对应的最终输出传入扩展。逐页串行、有限等待、完成后关闭；限流停止，失败保留缓存。
- C（正常访问收录）：已在真实 Chrome 156 中从任务页面进入一条真实任务，核对完整 331 字输出与原来源逐字一致，并在 Start 首页和全文弹窗显示。后台加载可能先遇到站点验证页，不能据此宣称来源永久不可用。
- 安装级测试使用本地产生的 HTTPS 合成来源及独立 Profile，覆盖 B、C、去重、全文、分页、账户切换、关闭后的迟到写入、生活模式、缓存重载、限流和四套主题。测试专用 manifest 预授予生产版同样的可选权限，运行文件不改；这不认证操作系统的首次授权弹窗。
- 已完成的真实 C 验证使用现有授权开发 Chrome Profile，与主 Chrome 的账户范围不同。真实 Edge 账户同步未认证；Edge 安装级流程使用合成来源。

构建与测试回执绑定具体 SHA；以开发包内 `build.json` 和 `verification/` 为准。本功能不代表整体 Free V1 的其他原生账号/Project 验收已完成。没有生产部署、商店发布或付费 API 调用。

## R1–R6

四主题的既有首页护栏通过安装级自动检查：无项目/会话/窗口计数，无首页时间跨度条，单个工作/生活切换按钮，项目头部仅 `+`，最近分组保持原契约，两种项目卡布局及稳定顺序不变。任务条位于书签区后、工作空间前；不写入项目布局或旧资料库。真实任务截图只补充任务条/全文的实机证据，不替代全部护栏测试。
