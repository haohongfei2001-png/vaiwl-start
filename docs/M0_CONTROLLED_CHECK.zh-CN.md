# M0 受控来源核验：一次操作组

适用：本包 `build.json` 所标识的完整提交。来源门仍为 `SOURCE_GATE_BLOCKED`，不是 Free V1 正式验收包。

## 准备与操作

1. **更新扩展。** 解压本包，将包内 `vaiwl-start` 的文件覆盖到此前已加载的同一个扩展文件夹，保留原路径；在 Chrome/Edge 扩展管理页对原 VAIWL Start 点击一次“重新加载”。若尚未安装，开启开发者模式后“加载已解压的扩展程序”。打开 Start → 设置 → 连接 ChatGPT，开启继续收录。不要卸载旧扩展或清除本地数据。
2. **准备合成对象。** 使用你自己选择的已授权测试账号：Project P 内有会话 C；另一个 Project Q 内有与 C 同名但不同的会话；N 明确未放入 Project。自然打开这些测试页面。不要把真实正文、附件、草稿用于取证。
3. **开始一次核验。** Start → 设置 → “查看来源状态与构建” → “受控来源核验”。核对页面显示的 SHA 与本包一致，点击开始。每个固定步骤只采样一次，整轮有效期 30 分钟。标签列表不展示私人标题，先用“查看所选标签”确认你选择的是测试页面。
4. **按核验页顺序操作。** A 基线 → P 主页 → Q 同名对照 → N → 从 Start 打开 C → 当天再次从 Start 打开 C → 只刷新 C → 可用时切换另一账号/空间。每次操作后刷新核验页的标签列表，再选择正确标签并采样。D 的两次主动打开应在点击后 60 秒内采样。P/Q 使用默认严格 parser，无需手工选取成员。
5. **需要结构采样时。** 页面右上角出现核验提示后，自然打开原生菜单，把鼠标停在“当前空间”或明确“没有 Project”的状态控件上，按 **Option/Alt + Shift + M**。它不读取文字、不执行该控件点击。若没有明确状态，点“跳过：没有明确状态”；不要选普通 `/c/` 地址、空白或聊天正文替代。默认 45 秒未选取就停止这次结构采样。
6. **结束并导出。** 点击“结束核验”，再点“导出脱敏报告”。只回传该 JSON 文件即可；不需要开发者工具、session JSON、token、cookie、网络响应或聊天截图。没有第二账号/空间时留空 A 对照，不阻塞导出。

## 明确停止条件

- 遇到不支持结构、没有明确原生状态、权限撤销、页面/账号发生竞争变化或超时，保留该结果，停止本步，不反复重新加载取证。
- 每种来源只有这一轮固定结构发现；其中的同名、切换、重复打开和刷新是预先规定的对照。页面不提供重置预算或自行开启可信来源的按钮。
- 只有出现新的有效证据，工程才可做一次有针对性的 profile 修订与复核。不要重新安装/重载来绕过预算重复试探。
- 正式 Chrome 与 Edge 的真实验收分开记录。本轮先在日常使用的一个浏览器完成上述操作组；在四项来源证明并接入正式适配器前，不重复做完整双浏览器旅程。

## 报告能证明什么

报告只包含构建、随机关联 ID、固定失败码、结构断言，以及用本轮随机密钥生成的 HMAC 别名。可比较 P/Q 的同名与不同 ID、主体候选是否变化、Start 意图是否绑定到目标文档。原始主体/空间/项目/会话 ID、标题、URL、HTML、正文、邮箱、凭证和密钥不会导出。

HMAC 别名是本轮诊断关联，不是账号认证。选取控件只证明它的结构，不证明它表示“当前 workspace”或“正向 NONE”。Project parser 的候选成功也不能代替当前 scope。导航绑定不证明 ChatGPT 已加载目标会话。**这份报告不能自动解锁来源门；若仍无语义来源，四项继续 BLOCKED。**

## 已实现的真实产品修复

Project SPA 切换会重新触发现有解析器，固定有限等待可覆盖原生元数据延迟渲染；同文档身份状态不再永久缓存；BFCache 恢复重新建立绑定；Start 导航会冻结目标文档/路由，刷新、错误目标、绕行和关闭使意图失效。候选链接仍可保存、搜索、打开，未证实的归属与活动保持关闭。
