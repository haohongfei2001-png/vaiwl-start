# 首页主题：经典、空间、分区与书页

在 **设置 → 新标签页 → 首页主题** 中选择。经典仍是默认值；旧用户升级后不会自动切换。主题与工作／生活模式独立，设置成功后，同一浏览器资料中的其他 Start 标签页会同步主题，新标签页也会沿用该选择。

| 主题 | 存储值 | 布局 |
| --- | --- | --- |
| 经典 | `classic` | 保留原有首页与导航 |
| 空间 A | `spatial` | 全宽项目网格，下方连续日期带 |
| 分区 B | `workbench` | 项目主区与右侧时间线；窄窗口恢复上下布局 |
| 书页 C | `folio` | 无卡框项目、细书脊与开放日期分栏 |

## 三个新主题的共用顶部

常驻品牌名称、标记与大号工作区标题退出视觉主区；语义标题仍供辅助技术使用，产品身份保留在设置。56px 操作栏整合工作／生活切换、全部／项目／最近筛选、30 天区间、短搜索、新对话和设置。搜索默认约 200px，随视口调整，在使用时打开完整搜索对话框。

浏览器书签独占紧随其后的一行，沿用原生名称、顺序、文件夹层级、溢出算法与 Chromium favicon 缓存路径。不会把浏览器自己的垂直标签栏当作扩展侧栏。≤720px 的操作区改为两行；存在本地资料库选择器时，≤1050px 提前改为两行，避免挤压操作项。

30 天区间作用于项目和最近会话；完整起止日期保留在区间提示中。经典仍使用原有右侧导航。

## 数据、密度与展开

三个新主题只呈现现有 `projectCatalog` / `recentDisplayGroups` 的同一份投影，不创造项目归属，不复制目录，不迁移数据库，也不把来源观察时间当作会话活动时间。

- 项目自然高度，每个预览四条。其余会话在所属整行之后展开，先展示二十四条，再按四十八条增加；会话可直接进入，也可搜索此项目。
- 最近按真实日期连续组织，每组先显示九条，再按二十四条增加；只能证明所在区间时，显示区间而不编造具体日期。
- 项目或会话标题保留原始完整文本和链接；视觉截断不改数据，标题提示及辅助名称提供完整内容。
- 分区主题右侧历史与项目一起整页滚动，不引入嵌套滚动。只有项目或只有最近时，不留下空白侧区。
- 书页的日期网格按 DOM 顺序逐行排列，不使用瀑布流重排。某天展开可能增高所在行，这是保持日期顺序的取舍。

内容最大宽度 1456px，空列不自动拉伸为巨卡片。项目列数和展开插入算法必须共同维护：

| 可用视口宽度 | 空间 A | 分区 B | 书页 C |
| --- | ---: | ---: | ---: |
| >1180px | 4 | 3＋历史侧区 | 3 |
| 1051–1180px | 3 | 2＋历史侧区 | 3 |
| 851–1050px | 3 | 3，历史在下方 | 2 |
| 601–850px | 2 | 2，历史在下方 | 2 |
| ≤600px | 1 | 1，历史在下方 | 1 |

B 在 1050→1051px 时从三列变成两列，是给加入的侧区留出可读宽度。A 的日期及展开列表在 ≤1050 / ≤600px 时调整为 2 / 1 列；B 侧区始终单列日期；C 日期、展开列表跟随其 3 / 2 / 1 列规则。

## 状态与实现边界

`native.homeTheme` 保存在 `chrome.storage.local`，只接受 `classic | spatial | workbench | folio`。缺失或非法值回到经典；保存失败保留当前主题并显示错误。控制器监听存储事件，阻止过期异步读取覆盖新选择。生活模式下切换主题不加载工作区目录，工作区和顶栏目录控件清空。

现代布局共用 `src/ui/spatial-home.ts`，展开状态保存于独立页内 `sessionStorage`；切换主题保留展开目标并按新的列数重新定位。共享样式限定于三个现代主题，B/C 的覆盖样式分别限定自身主题；不改变经典匹配范围。

顶部主题属性与工作区内容在现有 `SafeRendering` 下同步更新，保留键盘焦点和滚动锚点。跨标签页更新等待当前指针、键盘或输入法操作结束，也不丢弃已排队的更新目录。记录离开投影时，焦点可回到移入顶栏的当前筛选。回到最新 30 天后，焦点避开已禁用的“更新”按钮。

没有新增权限、远程字体、运行时依赖或会话正文访问。本轮主题指布局与对应浅色视觉语言；没有引入新的深色模式偏好。

## 验证与交付边界

```sh
npm run verify
node tests/browser/home-theme.mjs
VAIWL_BROWSER_CHANNEL=msedge VAIWL_TEST_BROWSER_FAMILY=edge node tests/browser/home-theme.mjs
```

`home-theme.yml` 对 PR 的确切 head commit 执行类型、单元、权限/CSP/包完整性检查，以及安装后的 Chromium 与 Microsoft Edge 测试。浏览器脚本使用一次性的合成目录与独立资料，不读取用户账号。实际安装结果以对应提交的 Actions 报告为准。

本地 HTML 评审页使用真实构建后的首页及明确标注的示例数据，适合核对视觉、响应式、展开、搜索和设置切换；它不是浏览器扩展安装验收，也不能验证真实 favicon 缓存或用户账号。示例夹具只存在于 ignored artifacts，不进入生产 dist。

本次为可审阅的主题候选；本地验证与打包不代表已推送、合并、发布或更新用户设备上的扩展。
