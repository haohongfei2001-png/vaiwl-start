# 首页主题：经典、空间、分区与书页

在 **设置 → 新标签页 → 首页主题** 中选择。经典仍是默认值；旧用户升级后不会自动切换。主题与工作／生活模式、时段长度、卡片布局分别保存，设置成功后，同一浏览器资料中的其他 Start 标签页会同步，新标签页也沿用该选择。

四个主题共同遵守 [第 16 号全主题设计规范](free-v1/16-HOME-THEME-DESIGN-GUARDRAILS.md)，当前能力与验证边界见 [第 17 号实现说明](free-v1/17-HOME-THEME-GUARDRAILS-IMPLEMENTATION.md)。四主题共用紧凑顶栏、项目与最近渲染逻辑和响应式栅格；切换主题只改变视觉材质，不改变内容资格、展开规则或布局偏好。最新设计裁决见 [工作空间重构](evidence/workspace-design-20261105/DESIGN.md)。

| 主题 | 存储值 | 布局 |
| --- | --- | --- |
| 经典 | `classic` | 中性白底、清晰边界与项目层级线 |
| 空间 A | `spatial` | 柔和表面、绿灰中性色与自然留白 |
| 分区 B | `workbench` | 冷灰工具面、紫灰重点色与清晰标题分区 |
| 书页 C | `folio` | 纸色底、开放项目与细书脊 |

## 顶部、模式与时段导航

四个主题都只有一个小型工作／生活模式按钮。按钮显示当前模式，提示、可访问名称与切换图标说明点击目标；点击一次即反向切换。全部／项目／最近是内容筛选，与模式切换独立。

全部主题共用紧凑顶部：常驻品牌名称、标记与大号工作区标题退出视觉主区，语义标题仍供辅助技术使用，产品身份保留在设置。60px 操作栏整合模式切换、内容筛选、相邻时段箭头、短搜索、新对话和设置。搜索默认 184px，随视口调整，使用时打开完整搜索对话框。

浏览器书签独占紧随其后的一行，沿用原生名称、顺序、文件夹层级、溢出算法与 Chromium favicon 缓存路径。不会把浏览器自己的垂直标签栏当作扩展侧栏。≤760px 的操作区改为两行；存在本地资料库选择器时，≤1050px 提前改为两行，避免挤压操作项。

首页不显示“过去多少天”、起止日期范围或相关区间提示。四个主题都在工作区操作区保留紧凑的“更早时段／更新时段”箭头，经典的旧右侧浮动时间导航已退出。箭头逐段访问相邻范围，不跳过空时段；最新段的“更新时段”不可用。

浏览历史或启用内容筛选时，箭头旁出现一个“回到最新并显示全部工作”的小图标按钮，保留原品牌入口的一击复位能力。复位后焦点回到“全部”筛选；默认首页不显示这个额外动作。

在 **设置 → 新标签页 → 首页布局 → 每个时段** 中选择 **7／30／90 天**，默认 30 个本地自然日，作用于项目与最近投影。改变长度时按原时段结束日重定位历史浏览位置，只重算呈现，不改变真实活动时间。“今天”“昨天”和真实单日日期仍可作为最近分组标题。

## 数据、密度与展开

四个主题呈现现有 `projectCatalog` / `recentDisplayGroups` 的同一份投影，最近分组由共享 `selectRecentPresentation` 选择。不创造项目归属，不复制目录，不迁移数据库，也不把来源观察时间当作会话活动时间。

- 首页、相关设置和导入反馈不显示项目、会话或窗口数量，标题、角标、工具提示与可访问名称也不补回计数。分页仍可在内部计数；界面只写“展开更多”“收起”或“显示更多”。日期和设置中的时长选项不属于内容计数。
- 项目预览四条真实成员。其余会话在所属逻辑行之后的独立整行区域展开，先展示二十四条，再按四十八条增加；会话可直接进入，也可在展开区搜索此项目。上述批次是实现规格，不显示在用户界面中。
- 已取消全局“收起项目”。旧视图状态中的该选项归一为未收起；需要只看最近时使用“最近”筛选。单项目展开仍保留。
- 项目或会话标题保留原始完整文本和链接；视觉截断不改数据，标题提示及辅助名称提供完整内容。
- 最近每组先显示九条，再按二十四条增加，分页按钮不显示剩余数量。

### 项目右上角的「＋」

项目卡右上角只有一颗加号，没有三点菜单、打开、搜索或其他头部操作按钮。项目名称仍链接到原项目页面。

当前工程只验证了 `/g/<project-id>/project` 项目主页，没有可信的项目内新建对话入口。因此本版本的「＋」**可聚焦但处于 `aria-disabled` 状态**，提示与可访问说明明确表达暂不可用，不执行导航或伪造创建行为。项目主页不能冒充新建入口，也不会退化为通用 ChatGPT 新对话。启用该能力需要另行验证原生入口。

### 最近的默认分组与置顶

默认依次显示非空的 **置顶 → 今天 → 昨天**。置顶来自用户在最近区顶部“管理置顶”中的明确选择，同一会话只出现一次；没有内容的分组不留空框。管理入口在首次没有置顶时也可达。

置顶只重组当前资料库、当前时段中已有资格进入最近区的记录，不把项目成员重新归类为最近，不改变原生归属、记录身份或活动时间。管理界面也允许取消其他时段已有的置顶。若三个默认分组都为空，则展示所选时段内最近的真实日期及其会话，不从其他时段借用内容。

最近区末尾的一个小箭头展开／收起其余分组，无剩余内容时不显示。其名称是“展开更多日期／收起更多日期”，与时段前后导航区分。只能证明所在时段、不能确定日期的记录使用“本时间段”中性标题，不显示范围字符串；有默认分组时随更多内容展开，没有真实日期或置顶可作为主分组时作为可见回退。更早时段不会被标为今天或昨天。

### 卡片布局与响应式

**设置 → 新标签页 → 首页布局 → 项目卡片** 提供互斥的“等高卡片”和“按内容自适应”，默认为后者，换主题不会重置。

- **等高卡片**：同一断点的项目卡保持共同宽高，只有一个会话也占完整高度。当前高度基准为 256px，≤600px 为 280px，粗指针为 296px；更多内容通过卡片外的展开区域访问，不撑高单张卡片。
- **按内容自适应**：按实际预览内容测量高度，后续卡片进入最短列，填补短卡下方空间。DOM 与项目原始排序不变，视觉按纵坐标、再按横坐标阅读，与键盘顺序一致。整行展开区形成布局分界，后续卡片从其下方继续排列。

全部主题的内容最大宽度为 1360px。桌面页边距48px，≤1180px为36px，≤850px为24px，≤600px为20px。项目空列不自动拉伸成巨卡片。项目、最近组内会话和项目展开区使用同一列线：

| 视口宽度 | 四个主题共用列数 |
| --- | ---: |
| >1180px | 4 |
| 851–1180px | 3 |
| 601–850px | 2 |
| ≤600px | 1 |

项目在上、最近在下，分区主题不再为稀疏最近预留固定侧栏。日期组保持置顶、今天、昨天和真实日期的既定顺序；每组内会话逐行排列。最近只含一个会话时最多跨两列，提供受控的长标题阅读宽度；一列窗口恢复单列。没有虚构模块、巨型日期卡或按视觉需要制造的新分组。

## 状态与实现边界

以下偏好分别保存在 `chrome.storage.local`，缺失或非法值回到默认值，保存失败保留原有效选择并显示反馈。控制器监听存储事件，阻止过期异步读取覆盖新选择。

| 偏好键 | 可选值 | 默认值 |
| --- | --- | --- |
| `native.homeTheme` | `classic / spatial / workbench / folio` | `classic` |
| `native.homePeriodDays` | `7 / 30 / 90` | `30` |
| `native.projectLayout` | `adaptive / equal` | `adaptive` |
| `native.recentPinnedKeys` | 用户明确选择的会话键 | 空集合 |

生活模式下调整主题和布局不会加载工作区目录；工作区内容和顶栏目录控件清空，既有模式持久化、失败恢复及资料隔离继续有效。

四个主题共用 `src/ui/spatial-home.ts` 与 `src/ui/project-layout.ts`。项目／日期展开和分页使用独立页内视图状态，最近的更多分组状态也与内容偏好分离；切换主题保留展开目标，并按新列数重新定位。各主题文件提供颜色与材质 Token，`public/home-layout.css` 为全部主题提供共享的布局和组件。设置中的主题缩略图与说明也使用相同构图。

顶部主题属性与工作区内容在现有 `SafeRendering` 下同步更新，保留键盘焦点和滚动锚点。尺寸、字体、布局及跨标签页偏好更新等待当前指针、键盘或输入法操作结束，不丢弃已排队的目录更新。记录离开投影时，焦点可回到当前筛选；回到最新时段后，焦点避开已禁用的“更新时段”按钮。卸载网格时清理尺寸观察器、字体事件与待执行布局，避免失效视图继续写入。

没有新增权限、远程字体、运行时依赖或会话正文访问。本轮主题指布局与对应浅色视觉语言；没有引入新的深色模式偏好。

| 规则 | 当前实现与本地验证 | 已安装浏览器验证范围 |
| --- | --- | --- |

| R2 设置时段长度 | PASS：7／30／90 天、真实日期与历史锚点测试 | 相邻翻阅、空段及最新段边界 |
| R3 单模式按钮 | PASS：唯一控件复用原模式控制器 | 语义、双向切换及生活模式隔离 |

| R5 最近与置顶 | PASS：分组、去重、回退、中性证据与偏好测试 | 置顶／取消／重载、更多分组与历史日期 |
| R6 双布局 | PASS：最短列、等高、顺序、展开、锚点与清理测试 | 四主题多宽度、混合内容和真实 200% 浏览器缩放 |

本表的 PASS 指代码与本地验证范围；已安装浏览器结果必须对应候选提交的 CI 收据。

```sh
npm run verify
node tests/browser/home-theme.mjs
node tests/browser/home-guardrails.mjs
VAIWL_BROWSER_CHANNEL=msedge VAIWL_TEST_BROWSER_FAMILY=edge node tests/browser/home-theme.mjs
VAIWL_BROWSER_CHANNEL=msedge VAIWL_TEST_BROWSER_FAMILY=edge node tests/browser/home-guardrails.mjs
```

`home-theme.yml` 对 PR 的确切 head commit 执行类型、单元、权限/CSP/包完整性检查，以及安装后的 Chromium 与 Microsoft Edge 测试；同时保留设置、响应式、工作区和书签回归。浏览器脚本使用一次性的合成目录与独立资料，不读取用户账号。实际安装结果以对应提交的 Actions 报告为准，不把 CI 的 Chromium 或示例资料验证冒称为用户设备验收。

本地 HTML 评审页使用真实构建后的首页及明确标注的示例数据，适合核对视觉、响应式、展开、搜索和设置切换；它不是浏览器扩展安装验收，也不能验证真实 favicon 缓存或用户账号。示例夹具只存在于 ignored artifacts，不进入生产 dist。

本次为可审阅的主题候选；本地验证与打包不代表已推送、合并、发布或更新用户设备上的扩展。
